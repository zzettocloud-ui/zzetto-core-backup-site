Política de Privacidade

Esta página descreve o uso de dados pelo aplicativo pessoal ZZetto Core Backup. Contato do responsável: zzettocloud@gmail.com.

Dados acessados e finalidade

Com a autorização do proprietário, o aplicativo acessa apenas os arquivos do Google Drive criados ou usados com ele, por meio do escopo drive.file. Usa esses arquivos e seus metadados para criar, conferir e restaurar backups do banco do ZZetto Core.

Armazenamento e segurança

O banco é criptografado no servidor antes do envio ao Google Drive. O token de autorização fica na configuração privada do servidor. Os arquivos de backup permanecem na conta Google Drive autorizada até serem removidos pelo proprietário. O aplicativo não usa esses dados para anúncios nem os vende.

Compartilhamento

O Google Drive é o serviço de armazenamento escolhido pelo proprietário. O aplicativo não compartilha os backups com outras pessoas nem os envia a outros serviços por este fluxo.

Controle e exclusão

O proprietário pode revogar o acesso do aplicativo nas configurações de segurança da Conta Google. A revogação interrompe novos acessos, mas não exclui automaticamente os backups já armazenados. Para removê-los, o proprietário pode excluir a pasta ZZetto-Core-Private no Drive. Cópias locais do servidor são gerenciadas separadamente.

Alterações

Se o uso de dados mudar, esta página será atualizada antes de ampliar o acesso solicitado.
